## 2. Как устроено

`rasm_cim_v17/agent/`:

* `tools.py` — `Web.search()` / `Web.fetch()`: сеть **выключена по умолчанию**,
  проверка хоста по списку, таймаут 10 с, лимит 400 КБ, кэш в доме на сутки,
  ошибки возвращаются как ошибки. Провайдеры: Википедия, произвольный
  JSON-бэкенд (`{"results": [{title,url,text}]}`), `api.github.com`;
* `text.py` — нарезка на предложения, отбор релевантных по пересечению с
  вопросом, сжатие ответа, разбор определений, отсев оговорок («якобы»,
  «по слухам»);
* `memory.py` — словарный запас (`vocab`) и очередь фактов (`pending`); в граф
  факт попадает **только** после «да» или второго независимого источника;
* `session.py` — шаг диалога: интенты, уточнение, ответ по базе (включая класс
  и число через морфологию), словарный запас, поиск, пересказ, подтверждение.

CLI: `chat` (агентный по умолчанию, `--classic` — старый), `agent` (одна
реплика, `--json`), `vocab`. Флаги `--online`, `--endpoint`.

## 3. «Своими словами» — что это значит буквально

Ответ собирается **из предложений источника**: отбор по релевантности,
сокращение длинных предложений, удаление повторов, связка. Ни одного слова,
которого нет в источнике, кроме связки, не добавляется. Это пересказ, а не
генерация — и в отчёте это не выдаётся за генерацию.

Если релевантных предложений нет, ответа нет: «Нашёл источник, но ответа на
вопрос в нём нет. Не буду выдумывать».

## 4. Доказательства работы с реальной сетью

**Что доступно в этой песочнице:** только `github.com`, `api.github.com`,
`codeload.github.com`, `registry.npmjs.org`, `pypi.org`,
`files.pythonhosted.org`. Остальной интернет закрыт на уровне окружения.

Реальный запрос (не имитация), провайдер `github`:

```
$ python -m rasm_cim agent "поищи python knowledge graph" --online --endpoint github
Вот что известно: 小型金融知识图谱构建流程（neo4j / python / cypher / KG）

Источник: https://github.com/jm199504/Financial-Knowledge-Graphs
```

**Википедия в этой среде недоступна** — TLS закрыт, и агент говорит об этом
прямо, а не отвечает по памяти:

```
$ python -m rasm_cim agent "Кто такой Кулибин?" --online
Не смог получить информацию: нет доступа к https://ru.wikipedia.org/w/api.php?...
(URLError: <urlopen error TLS/SSL connection has been closed (EOF)>).
Отвечать по памяти не буду — в базе этого нет.
```

Полный цикл «поиск → страница → отбор → пересказ → предложение → подтверждение
→ граф и словарь» проверен тестами на локальном стенде
(`tests_v17/test_agent_dialog.py`): тестовый HTTP-сервер отдаёт поисковую
выдачу и HTML-страницу, чтобы проверять именно логику, а не доступность
внешней сети.

## 5. Что покрыто тестами

`tests_v17/test_agent_dialog.py` (16):

* без сети агент не делает вид, что искал (`kind == "offer"`, «--online»), и в
  граф ничего не пишет;
* явная просьба «поищи» без сети — ошибка с причиной;
* светская часть и вопросы о себе;
* обучение фактом и последующий ответ;
* онлайн: ответ содержит источник, до подтверждения в граф ничего не пишется;
* «да» → факт в графе и словарном запасе; «нет» → ничего не записано;
* нерелевантный источник → «не буду выдумывать», ни кандидатов, ни записи;
* пустая выдача и HTTP 500 — честные ошибки;
* класс и число («Кто такие физики?»), словарный запас;
* многословный класс: «Москва — столица России» → «Москва — столица» + полная
  формулировка в словаре;
* отказ хосту вне списка разрешённых.

`tests_v17/test_agent_cli.py` (4): `agent`, `agent --json`, `chat --classic`,
агентный `chat`.

Инвариант «ядро офлайн» сохранён и усилен: сканер
(`rasm_cim_v17/robustness/offline.py`) теперь знает **ровно одно** исключение —
`agent/tools.py`; импорт сети в любом другом файле по-прежнему проваливает
тест, а разрешённые находки перечисляются отдельным списком.

Полный прогон: `tests_v16 tests_v17` — **680 passed**.

## 6. Чего этот слой не делает (и что нельзя утверждать)

* **Это не языковая модель.** Свободных рассуждений, связного текста «из
  головы» и обобщений здесь нет; «своими словами» = сжатый пересказ источника.
* **Общий интернет не проверен в этой среде.** Реальный сетевой путь проверен
  только на `api.github.com`; Википедия и произвольные сайты в песочнице
  закрыты. На машине пользователя с открытой сетью путь тот же, но его
  работоспособность там не измерялась — это INCONCLUSIVE.
* **Качество ответа зависит от источника.** Если источник нерелевантен или
  пуст, агент откажется отвечать. Гарантии «правильного ответа на любой вопрос»
  нет и быть не может.
* **Память консервативна.** Факт из сети пишется только после подтверждения;
  ядро принимает класс из одного слова, поэтому длинные формулировки
  сохраняются в словаре, а не в графе.
* **Android/ARM64** — по-прежнему INCONCLUSIVE, запусков не было.
