# Этап 0 — базовая точка, 2026-11-28

**Статус:** выполнен технический baseline на синтетическом корпусе, выбранном
пользователем. Это не оценка качества на реальных текстах: корпус мал, создан
ассистентом и не проверен носителями таджикского языка. Этап 1 не выполнялся.

## Данные и фиксированное разбиение

Оригинальные синтетические предложения созданы для этого эксперимента без
внешнего источника; условия распространения — MIT, см. корневой `LICENSE` и
[`README`](../experiments/stage0/data/README.md). В файлах по 30 записей на
русском и таджикском. Стратифицированное случайное разбиение с seed `20261128`
зафиксировано до запуска: по 20 записей каждого языка в train, по 5 — в
validation и по 5 — в test. Индексы и порядок находятся в
[`split.json`](../experiments/stage0/data/split.json); хеши исходных текстов,
разбиения и промптов — в [`manifest.json`](../experiments/stage0/data/manifest.json).

SHA-256 разбиения: `e684b74859d5058df858e98a1535c883c7ea94213df00f33c3e50a44acbce78d`.
Проверка в скрипте перед запуском обнаружила 0 повторов после NFC, casefold и
нормализации пробелов во всех частях; в ней также проверяются полнота разбиения
и хеши. Это **не** проверка семантических перефраз или точности языка. Test не
использовался для обучения, измерения loss или генерации. Его не следует
менять для улучшения результатов.

## Модель и конфигурация

Базовая точка — существующий мобильный `modelforge.mobile.offline.train`,
запущенный на CPU, а не `TrainingEngine` серверного приложения. Это обучение
с нуля, не оценка ранее обученного пользователем чекпоинта. Базовый код и
протокол зафиксированы коммитом `21c82e9ed6b867e20fa36f38edb695f40b29004d`.
Использовался символьный токенизатор, обученный только на train. Конфигурация:
`tiny_transformer`, 1 слой, ширина 64, 4 головы, контекст 16, 1 проход,
словарь 158 токенов, seed 42, 61 632 параметра; FP32-веса приблизительно
0,2351 МиБ при целевом верхнем размере 1 МиБ. Мобильный код использует до двух
эпох, до 24 окон на эпоху, SGD с learning rate 0,03 и clipping; выполнено
48 шагов. Это существенно меньше ориентира пользователя для будущих
экспериментов и не является обучением на Android.

Полный конфиг — [`config.json`](../experiments/stage0/config.json), сохранённый
фактический конфиг и окружение — [`environment.json`](../experiments/stage0/runs/baseline_seed42/environment.json).
Заданный `available_mb_guard=512` — программный входной лимит, **не измерение**
доступной памяти телефона. Граница времени `max_seconds=600` не достигнута.

## Команды и окружение

```sh
python3 -m venv .venv
.venv/bin/pip install -e '.[full,dev]'
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 \
  .venv/bin/python scripts/stage0_baseline.py
.venv/bin/python -m pytest -o addopts='' -q | tee experiments/stage0/runs/baseline_seed42/pytest.log
```

Для воспроизведения требуется чистый checkout указанного коммита и отсутствие
каталога результатов: скрипт намеренно отказывается перезаписывать его.
Сохранены версии зависимостей (`pip freeze`), Python 3.11.2, NumPy 2.4.6,
Linux x86_64, значения ограничений потоков, seed, хеши скрипта, конфигурации,
корпуса и чекпоинта. Конкретные версии следует брать из `environment.json`;
числовые результаты запуска — из [`results.json`](../experiments/stage0/runs/baseline_seed42/results.json).
Запуск на ПК не подтверждает производительность или потребление памяти телефона.

## Фактические результаты validation

Для каждой записи контекст сбрасывается. Скорится каждый Unicode-кодпоинт ровно
один раз как следующий символ, при наличии BOS в контексте; EOS не скорится.
Loss — средняя отрицательная log-вероятность в натуральных логарифмах на символ,
BPC = loss / ln(2). Все символы validation оказались в словаре; `<unk>` не
использовался. Строки не нормализовались как этап обработки данных; проверка
выше применяется только к обнаружению совпадений. Общее значение взвешено по
числу символов.

| Validation | Записей | Символов | Loss, nats/символ | Bits/character |
|---|---:|---:|---:|---:|
| Русский | 5 | 216 | 4,00835 | 5,78282 |
| Таджикский | 5 | 205 | 3,83922 | 5,53882 |
| Вместе | 10 | 421 | 3,92599 | 5,66401 |

Полученные значения не сопоставимы без изменения протокола с loss текущего
`EvaluationEngine`, который использует перекрывающиеся окна и может выбирать
test. При сравнении следующих конфигураций нужен тот же подсчёт символов и те
же закреплённые записи. Время, сообщённое мобильным trainer при этом запуске:
0,06 с; это не бенчмарк телефона. Всего скрипт сообщил 0,56969 с, включая оценку
и генерацию. Точность временных значений и воспроизводимость зависят от машины.

## Генерация и отрицательный результат

[Десять фиксированных промптов и все фактические продолжения](../experiments/stage0/runs/baseline_seed42/generation.json)
сохранены без ручного исправления. Генерация выполнялась текущим мобильным
`generate`: greedy argmax, до 48 символов, с сохранёнными весами. Выходы состоят
преимущественно из пробелов и иногда буквы «а»; осмысленные ответы не получены.
Это отрицательный результат на данном наборе; возможные причины включают малый
синтетический корпус, малое число шагов и модель с нуля, но причинный вклад не
измерен. Первый и последний тренировочные loss из разных окон не доказывают
улучшение validation.

Чекпоинт: [`offline_model.npz`](../experiments/stage0/runs/baseline_seed42/offline_model.npz),
SHA-256 `eb7d85db973bcdbfae0048dbbd357d227d5268691d745e79711857d6c79f4f4b`.
Скрипт загружает сохранённые веса перед расчётом и генерацией; trainer проверяет
изменение весов и не сохраняет их при отсутствии изменений. `pytest -q`: 38
тестов прошли, 1 предупреждение о `StarletteDeprecationWarning`.

## Что не проверено

Реальные русские и таджикские корпуса, качество перевода/грамматики, пиковый RSS,
физический Android с 3 ГБ RAM и сравнение архитектур не исследовались. В текущей
среде нет физического телефона. Если такой тест потребуется, необходимо будет
получить устройство и согласовать метод замера. Синтетический baseline годится
для проверки pipeline, но не даёт обоснований о качестве на реальных данных.
