# BENCHMARK_REPORT.md — v0.10 (host; свежая среда, 2026-11-26)

Метод: **каждая ячейка = изолированный subprocess**, медиана из 3 повторов (диапазоны —
в results_v10/profile_matrix.json), одни данные/seed/пробы для v0.8(v2) и v0.10(v3).
Инструментальная честность: tracemalloc кратно раздувает латентность (обнаружено на этом
этапе!) — поэтому латентные ячейки идут БЕЗ аллокационного трейсинга, а build-ячейки
пишут wall дважды (без трейса и с ним), и в отчёте wall = non-traced.
Среда: Linux 6.1.189+, 2 CPU, 1982 MiB, Python 3.13.18, /tmp=tmpfs (fsync-цифры
оптимистичны), numpy 2.3.5 (auto-sort включается ≥200k).
ВСЕ числа — host; устройствые (в скобках пометка device) лежат строго в
results_v9/device/ и сюда не перемешиваются.
