# LIMITATIONS.md — v0.11

1. **Язык**: только русский. Английский/таджикский/др. → `unknown` (by design).
   Никаких заявлений о «понимании» или «интеллекте» не делается.
2. **Морфология**: псевдо-стемминг суффиксами, не полноценная лемматизация;
   словаря словоформ нет; покрытие ограничено частотными окончаниями; несовпадение →
   честный UNKNOWN, не угадывание. Нет разбора частей речи в строгом смысле, тема/род/число
   не определяются (кроме грубых признаков для будущих местоимений v0.13).
3. **Intent**: 7 классов, одно сообщение = один класс; много-вопросные сообщения
   классифицируются целиком (разбивка — v0.13). Правила стеммятся на маленьком тем-
   корпусе (161 пример): обобщение на естественный шум, опечатки, сленг — НЕ доказано.
   dev 0.963 с известной ошибкой («Добрый вечерок» → unknown) сохранён как есть.
4. **Корпус**: тем-генерирован, нет орфографических ошибок/сленга/code-switch;
   test=48 — мелкий, 1.000 не экстраполируется на реальные запросы.
5. **Demo-ответчик** не заменяет pipeline (не проверяет доказательства, не ранжирует,
   не объясняет отказ кроме статуса); полный контур — v0.14.
6. Вопросительные и не вопросительные омографы («Он пришёл домой.» против «Когда он
   пришёл?») детектируются только формой («?»/вопросительные слова), без синтаксического
   анализа.
7. Числительные: только 0..1000 словесно; «две тысячи двадцать шесть» не парсится.
8. Запятые-разделители внутри numbers («1,000,000») не различаются от десятичных.
9. NFKC может склеить то, что пользователь хотел различить (²→2 и т.п.); оригинал
   сохраняется всегда, нормализация применяется к вводу, не к хранимым фактам.
