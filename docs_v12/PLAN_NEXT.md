# PLAN_NEXT.md — v0.13 (диалог, контекст, несколько вопросов)

Цель v0.13: короткий многошаговый диалог с разрешением местоимений и разбиением
мульти-вопросных сообщений, БЕЗ потери provenance и с защитой от контекстного загрязнения.
- ContextStore: ограниченный размер (max turns) + TTL; offline; JSON-сериализация;
  восстановление после рестарта; отдельно от долговременной KB.
- Хранить: turns, активная тема, последние сущности/отношения, открытые вопросы,
  ссылки на provenance-id фактов.
- Местоимения (он/она/они/его/её/их…) и эллипсис («А его столица?») — ограниченное
  разрешение для русского; при ≥2 кандидатах → уточняющий вопрос, не случайный выбор.
- Разбиение сообщения на 2–4 подвопроса (по «?», «;», ", и/а + вопросительное слово",
  нумерация "1) 2)") — обработка по порядку, общий контекст.
- Уточняющие вопросы для неоднозначных/неполных/конфликтующих случаев.
- Команды: reset-context, show-context, export-session; чувствительные данные не логировать.
- Защита от загрязнения: цитаты/примеры/гипотетики ("допустим", «например», «представь»)
  НЕ становятся фактами; явное "запомни:" — отдельный путь teach.
- Тесты: 2–5 репликовые сценарии, смена/возврат темы, неоднозначные местоимения,
  мульти-вопросы 2–4 шт (все обнаружены и отвечены в порядке либо явно помечены).
