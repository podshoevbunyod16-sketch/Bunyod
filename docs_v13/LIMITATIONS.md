# LIMITATIONS.md — v0.13

1. **Местоимения — только личные/простые демонстративы**, без участия синтаксиса;
   род определяется эвристикой окончаний (ошибки → CLARIFY, не ложный выбор).
   «это/то» не референция (консервативно). Связь «его»/«её» с неодушевлёнными сущностями
   работает только если родовая эвристика совпала; иначе UNKNOWN.
2. **Разрешение — только по recent_entities (≤12, MRU) и последнему user-turn для мн.ч.**;
   глубоких цепочек (референция через 3+ реплики) нет by design; TTL 30 минут по умолчанию.
3. **Сплиттер** — эвристика (числа, '?', ';', союзы с вопросительными сторонами); ждёт ≤8
   вопросов; не идеален для сложных придаточных с «?» внутри. Каждый подвопрос
   обрабатывается независимо — общие придаточные («сначала скажи X, а потом Y») не анализируются.
4. **Эллипсис** — только форма «местоимение + ключевое слово предиката»; конструкции
   «А у Франции?» (предложная группа без предиката) получают CLARIFY.
5. **compare** даёт только обе is_a-стороны (partial), числовые сравнения (выше/больше
   по факту) — не реализованы до v0.14/чисел.
6. **list** требует, чтобы категория была известной сущностью KB и предметы были
   связаны is_a к ней; произвольные классификации не выводятся.
7. **teach-парсер** — 3 паттерна; сложные/непрямые факты («между Францией и Испанией
   Пиренеи») не распознаются — нужен полный переписывание в v0.14+.
8. **Ответы не грамматически согласуются по шаблонам уровня филологии** — читаемы,
   «стойкие» в стандарте, но не литературные; факты подставляются из KB.
9. **Один пользователь**; файловый контекст не для конкурентного доступа.
10. **Чувствительные данные**: turns сохраняются в открытом виде в context.json по месту —
    каталог должен лежать в приватной директории (документировано в REPRODUCE).
