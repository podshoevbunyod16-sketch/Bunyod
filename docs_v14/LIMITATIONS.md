# LIMITATIONS.md — v0.14

1. **Правила закрытые**: только R01–R03; нет правил дат, чисел, причинности, отмены
   единиц, кванторов «все/некоторые», отрицания в единицах измерения и т.п.
2. **Сравнительные ответы** — только над литералами population_of/height_of обеих
   сущностей (числа, latest-created выигрывает). Качественные сравнения («больше»
   без чисел) не выводятся.
3. **Приоритет типов при совпадении имён** фиксирован сидами (seeded type map);
   сущности с одинаковым именем, разные типы — по-прежнему существуют в KB;
   pipeline агрегирует доказательства по каждому, заглушает неподтверждённый
   дубль, если одноимённый факт дал ответ. Автомержа НЕТ (сознательно).
4. **Multi-hop ширина** ограничена (128 KB-чтений, 64 derived, глубина ≤3).
   «Далекие» факты (>3 транзитивных шагов) недостижимы; это конфигурируется.
5. **Вербализация** — шаблоны русского, не литературный русский; падежи
   подставляются как есть (именительный/форма kb-имени).
6. **confidence partial ≠ «может быть истиной»** — это «есть цепочка/неполнота»;
   UNKNOWN при частичных данных — намеренная честность.
7. **Evidence id коротки (16 hex sha256)** — коллизия практически невозможна в этом масштабе,
   но id — не криптографическая подпись.
8. **Чувствительность/опасность**: конвейер не знает про социальный риск своего текста —
   сеть доказательств это не перевешивает; provenance показывается, решений не принимает.
9. **Пропуск промежуточных правил в ответе**: цепочки перечисляются id, не «рассуждением» —
   нет объяснения «почему» на естественном языке, только «на основании чего».
10. **Бенчмарки — на демо-фикстуре** (11 вопросов с ручной разметкой), НЕ общий бенчмарк;
    цифры нельзя переносить на ниши за пределами домена iso расчитаны на воспроизводимый прогон.
