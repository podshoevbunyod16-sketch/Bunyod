# LIMITATIONS.md — v0.15

1. **Fallback, а не полноценная NLP-модель**: unigram Naive Bayes на 265 train-примерах;
   синонимы и морфология не обобщаются. Дельта accuracy +2.3–2.4pp при 2–4 срабатываниях
   fallback — маргинальна, не статистически значима (n=84/88).
2. **Corpus — синтетика**: 54 семейства × 34 факта; однообразие шаблонов; не передаёт
   стили, опечатки, диалоги, нет кодовых переключений, нет пунктуационного шума.
   Счётчик подтверждает engineering, не компетентность. Оценка на dev/test валидна ТОЛЬКО
   для этой синтетики и demo-домена.
3. **Predicate hints** — точное совпадение нормализованной строки вопроса; намеренно узко.
   Общность — обязанность fallback/keyword-слоя, не hint-таблицы.
4. **alias_delta** со спокойным контролем неоднозначности (нельзя перевязать занятую
   поверхность на другой объект); это НЕ синонимический словарь.
5. **Конфликтующие коррекции**: latest-wins c показом конфликтов; никакой автоматической
   семантики; человек должен разобрать вручную.
6. **История коррекций** — append-only с хэш-цепочкой, но не защищена от прямой правки файла
   с перезаписью хэшей (нет внешнего witness); verify даёт аудит, не гарантию.
7. **Correction events могут содержать персональные данные** (target_text с диалога);
   каталог `rasm_cim_v15/corrections.jsonl` исключён из git (см. .gitignore). Не экспортировать
   без явного согласия.
8. **verdict_acc измеряется только на KB-answerable подмножестве** (capital_of субъектная,
   can-fly deny, существует конфликт, wrote reverse) — is_a {o}-side и population намеренно
   исключены (нет данных/вопрос не из фактов); abstain для них покрыт тестами, а не метрикой.
9. **Регрессия из 6 проб** — дымовая проверка; полные 321 тест должны быть зелёные по отдельному
   прогону (см. results_v15/test_run.log).
10. **Таджикский** — не реализован; отдельный экспериментальный пакет в будущем. Никаких заявлений
    о поддержке абзац.
11. **Обучение ≠ понимание**: артефакт улучшает маршрутизацию неизвестных intent-фраз на ЭТОЙ
    синтетике; на другом домене его нужно переобучать/переоценивать.
