# Агентный слой (`rasm_cim_v17/agent`)

## Зачем

До этого слоя система умела одно: ответить на вопрос по базе фактов. На всё,
чего в базе нет, она говорила «Не знаю», не задавала встречных вопросов и не
имела доступа к внешним данным. Агентный слой добавляет **диалог**, **один
инструмент** (сеть) и **память с подтверждением**.

## Из чего состоит

| модуль | роль |
|---|---|
| `tools.py` | `Web.search()` / `Web.fetch()`: список разрешённых хостов, таймаут, лимит байт, кэш в доме, ошибки как ошибки. Провайдеры: Википедия, произвольный JSON-бэкенд, `api.github.com` |
| `text.py` | нарезка на предложения, отбор релевантных (`rank`), сжатие ответа (`paraphrase`), разбор определений (`parse_definition`), отсев оговорок |
| `memory.py` | словарный запас и очередь фактов; запись в граф только после подтверждения |
| `session.py` | шаг диалога: интенты, уточнения, поиск, ответ со ссылкой, подтверждение |

## Правила, зашитые в код

1. **Сеть выключена по умолчанию.** `AgentSession(online=False)` не делает ни
   одного запроса; фраза «поищи» возвращает «сеть выключена (включите
   --online)».
2. **Хосты по списку.** `ALLOWED_HOSTS` + проверка `hostname`, редиректы не
   разыменовываются — иначе список обходится одним 302.
3. **Ответ «своими словами» — это сжатие источника.** Никакой свободной
   генерации: `paraphrase` берёт только предложения источника, сокращает и
   соединяет; ссылка на источник обязательна.
4. **Нет релевантного предложения — нет ответа.** Агент говорит «в источнике
   ответа нет», а не пересказывает первый абзац.
5. **Память с подтверждением.** Факт сначала показывается пользователю
   («Записать как …?»), и только «да» пишет его в граф. Словарный запас
   пополняется тем же действием.
6. **Многословный класс.** Ядро принимает `X — это Y` с односложным `Y`;
   «Москва — это столица России» записывается как «Москва — столица», а
   полная формулировка остаётся в словаре — и это сказано в ответе.

## Команды

```bash
python -m rasm_cim chat                      # агентный диалог (по умолчанию)
python -m rasm_cim chat --classic            # старый режим
python -m rasm_cim chat --online --endpoint github
python -m rasm_cim agent "Кто такой Кулибин?" --online   # одна реплика
python -m rasm_cim agent "…" --json          # машинный формат
python -m rasm_cim vocab                     # словарный запас
```

В диалоге: `:help`, `:vocab`, `:online [on|off]`, `:quit`.

## Чего слой не делает

* не генерирует связный текст и не рассуждает — это пересказ источника;
* не ходит по произвольным сайтам: только разрешённые хосты (список
  расширяется явно);
* не пишет в память ничего без подтверждения или второго независимого
  источника;
* не заменяет `ask`: `ask` остаётся строгим вопросом к базе, `agent` — диалог.
