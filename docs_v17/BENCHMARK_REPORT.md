## Что этот отчёт НЕ говорит

1. **38 реплик — это мало.** Доверительный интервал на таком объёме широкий:
   «97 %» здесь означает «примерно 95–99 % на похожих фразах», а не «97 % на
   любом русском».
2. **Корпус написан авторами кода.** Он проверяет регрессии и вскрывает
   конкретные дефекты (что и произошло: h01, h05, h06, i22), но он не является
   независимой оценкой. Независимый корпус — задача следующего шага.
3. **unsupported rate = 0 % — структурный факт**, а не гарантия правдивости:
   он означает, что у каждого факта в ответе есть строка в журнале источников.
   Он не означает, что источник верен.
4. **Нет замеров на ARM64/Termux**, нет Python 3.14, нет сравнения с внешними
   системами (внешние LLM в проекте запрещены как генератор).

## Воспроизводимость

* корпус и seed лежат в репозитории, sha256 печатается в отчёте;
* демо-база строится только через `teach` и импорт Плана A — прямых записей в
  граф нет (`rasm_cim_v17/semantics/harness.py`);
* метрики считаются на том же `SemanticPipeline`, который обслуживает CLI
  (`rasm_cim_v17/pipeline.py`), а не на отдельной «измерительной» копии;
* регрессионный порог закреплён тестом
  `tests_v17/test_plan_b_metrics.py::test_baseline_metrics_do_not_regress`:
  снижение чисел валит сборку.
