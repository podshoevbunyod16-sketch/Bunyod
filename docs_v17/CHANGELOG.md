# CHANGELOG v0.17

## 0.17.0 — 2026-11-27 — План A: интеграция v0.11–v0.16

### Добавлено

* `rasm_cim_v17/interop/legacy.py` — чтение `rasm-cim-kb/1` (каталог или
  `events.jsonl`) и v0.11 `demo_facts.jsonl`. Поведение при сбоях совпадает с
  писателем v0.12: torn-tail пропускается и считается, битая строка в
  середине логируется с номером, неизвестное событие — ошибка, а не тишина.
* `rasm_cim_v17/interop/learned.py` — чтение `rasm-cim-learned/1` с проверкой
  sha256 по `current.json`; фолбэк интентов пере-реализован из счётчиков
  (alpha=0.5), поэтому код v0.15 не импортируется.
* `rasm_cim_v17/interop/mapping.py` — таблица «предикат v0.11/0.12 → отношение
  v0.16»: pass-through, кастомные отношения (данные), нормализация булевых
  свойств, политика `hypothesis → skip`, отображение типов сущностей.
* `rasm_cim_v17/interop/importer.py` — `build_plan` (dry-run) и `apply_plan`
  (идемпотентно, с `import_ledger.json`, sha256 источника, digest плана,
  резервными копиями и `restore`).
* `rasm_cim_v17/routing.py` — `routing.json` (`rasm-cim-routing/1`) для
  `predicate_hints`: подсказки маршрута отдельно от знаний.
* `rasm_cim_v17/verify.py` — проверка целостности: висячие id, незарегистрированное
  отношение, дубли, осиротевшие записи об источниках, мёртвые подсказки,
  исчезнувшие источники импорта.
* `rasm_cim_v17/cli.py`, `__main__.py` — 16 команд, `--home`, `--json`.
* `rasm_cim/__main__.py` — **исправлен D1**: `python -m rasm_cim` больше не
  падает, а открывает единый CLI.
* `tests_v17/` — 91 тест (читатели, таблица, импортёр, CLI, verify),
  включая импорт реального корпуса v0.11 (34 факта) и двухпроцессную проверку
  общей базы.
* `.github/workflows/ci.yml` — матрица 3.10–3.13 + отдельная задача для v0.17.

### Изменено

* `pyproject.toml`: версия 0.17.0, добавлены пакеты `rasm_cim_v17(.interop)`,
  скрипт `rasm-cim = rasm_cim_v17.cli:main` (старые скрипты сохранены).
* `README.md` переписан под актуальное состояние (раньше описывал v0.10).

### Не менялось

* `rasm_cim_v16/**` — ни один файл ядра не тронут; 348 тестов v0.16 проходят.
* Публичные API v9/v16 и исторические пакеты — без изменений.
* Форматы на диске: `kb.json` schema=2, `context.json` — прежние; v0.17
  добавляет только отдельные документы (`import_ledger.json`, `routing.json`).

### Известные ограничения

См. `docs_v17/LIMITATIONS.md`: контекст v0.13 и журнал коррекций v0.15 не
импортируются; Python 3.14 / ARM64 / Termux не проверены; качество языка
пока не измеряется (нет размеченного корпуса в `main`).
