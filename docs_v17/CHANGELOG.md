# CHANGELOG v0.17

## 0.17.0 — 2026-11-27 — исправление: CLI больше не требует numpy

**Дефект, найденный в чистом окружении.** `python -m rasm_cim` (документированная
точка входа) падал с `ModuleNotFoundError: numpy`: пакет `rasm_cim/` — это
исторический прототип v0.1, и его `__init__.py` импортировал `fpe`/`cam`/`state`
(все на numpy) ещё до `__main__`. В прежней песочнице numpy был установлен, из-за
чего дефект не проявлялся, а на Termux он означал бы «CLI не запускается».

Исправление: имена прототипа (`RNS`, `IntegerFPE`, `ResidueFPE`,
`AssociativeMemory`, `DiagonalSSM`, `Resonator`, `RASMCIM`) загружаются по
первому обращению (PEP 562 `__getattr__`). Публичный API не изменился:
`from rasm_cim import RNS` работает как раньше, но numpy подтягивается только
тогда, когда он действительно нужен.

Регрессии: `test_entry_point_does_not_import_numpy`, `test_cli_works_without_numpy`,
`test_historical_names_are_lazy_and_still_present`.

## 0.17.0 — 2026-11-27 — План G: надёжность, офлайн, производительность

### Добавлено

* `robustness/fuzz.py` — детерминированный генератор «враждебных» входов
  (пустые, обрезанный UTF-8, 5 тыс. символов, эмодзи, zero-width, bidi,
  повторы) и прогон всей цепочки «разбор → смысл → ответ → план → текст»;
* `robustness/offline.py` — статическая проверка (через `ast`) импортов сетевых
  модулей и вызовов `curl`/`wget`; комментарий про `socket` нарушением не
  считается, `import socket` — считается;
* `robustness/perf.py` — холодный старт, p50/p95/максимум на запрос, пиковая
  память (`tracemalloc`), рост стоимости при увеличении базы;
* CLI `stress [--n --seed-number --json]`, `docs_v17/TERMUX.md`,
  17 тестов `tests_v17/test_plan_g_robustness.py`.

### Исправлено (найдено фаззингом и замером роста)

* **пустой ввод** (`""`, `" "`, `"\n\t "`) валил ядро v0.16 `IndexError`;
  v0.17 отвечает «Не знаю: пустой ввод.» до парсера;
* **`Resolution.best` вызывался как метод**, хотя в v0.16 это свойство:
  первое по-настоящему неоднозначное упоминание («Страна2» при «Страна0/1»)
  давало `TypeError`. Найдено замером роста базы, исправлено и закрыто тестом.

### Измерено

100 враждебных входов: 0 падений, 0 пустых ответов; 38 файлов — 0 сетевых
нарушений; p50 0,54 мс, p95 0,65 мс, пик 26 КБ на серию вопросов; рост ×0,98–1,16
при 88→263 утверждениях. ARM64/Termux — **не проверено** (`TERMUX.md`).

## 0.17.0 — 2026-11-27 — План E: связная генерация (ResponseIR + NLG)

### Добавлено

* `generation/response_ir.py` — `ResponseIR`, схема `rasm-cim-response-ir/1`:
  сегменты `claim / evidence / qualifier / refusal / clarification / correction /

* `generation/metrics.py` — `evaluate_plans`: доля утверждений с источником,
  доля планов с доказательством, средняя длина, повторы подряд, детерминизм.

  корпусе диалогов), 25 тестов `tests_v17/test_plan_e_generation.py`.

### Измерено

7 диалогов / 14 реплик: утверждения с источником 13/13 = 100 %, доказательство
включено в 42.9 % планов, средняя длина 1.86 предложения (58 символов), повторов
подряд 0 %, детерминизм да (`docs_v17/BENCHMARK_REPORT.md`).

  исправлений, исполнение на месте для исправленных актов.
* `semantics/corpus.py`, `metrics.py`, `harness.py` — формат корпуса
  `rasm-cim-eval-cases/1`, метрики (речевой акт, P/R/F1 сущностей, точность
