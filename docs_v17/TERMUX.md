# Termux / ARM64 — как запустить и что проверено

Целевая среда: Android, Termux, ARM64, ~3 ГБ RAM, без root и без GPU.
**На этой машине (Linux x86_64) проверить ARM64 невозможно**, поэтому документ
разделён на «проверено здесь», «пошаговый запуск» и «требует устройства».

## Пошаговый запуск в Termux

1. **Termux ставить из F-Droid**, не из Play Store: версия в Play Store
   устарела и ломает `pkg`. Ссылка: <https://f-droid.org/packages/com.termux/>.

2. Обновить пакеты и поставить Python и git:

   ```bash
   pkg update && pkg upgrade -y
   pkg install python git -y
   python --version          # ожидается 3.10+ (обычно 3.11/3.12)
   ```

3. Забрать репозиторий и запустить из него:

   ```bash
   git clone https://github.com/podshoevbunyod16-sketch/Bunyod.git
   cd Bunyod
   python -m rasm_cim version
   ```

   `python -m rasm_cim …` работает прямо из каталога репозитория, ставить пакет
   не обязательно. Если удобнее короткая команда `rasm-cim`:

   ```bash
   pip install --upgrade pip
   pip install .            # зависимостей нет, компиляции нет
   rasm-cim version
   ```

4. База и память агента лежат в `~/.rasm-cim/` (внутри домашнего каталога
   Termux). Если факты нужно держать на общей памяти телефона:

   ```bash
   termux-setup-storage
   python -m rasm_cim --home ~/storage/shared/rasm-cim stats
   ```

5. Научить паре фактов и спросить:

   ```bash
   python -m rasm_cim teach "Иван — это физик"
   python -m rasm_cim ask "Кто такой Иван?"
   python -m rasm_cim ask "Кто такие физики?"      # класс и число
   ```

6. Диалог и агентный режим:

   ```bash
   python -m rasm_cim chat              # диалог; :help, :vocab, :quit
   python -m rasm_cim chat --online     # + поиск в сети (инструмент включается явно)
   python -m rasm_cim agent "Кто такой Кулибин?" --online
   ```

   В диалоге: `:vocab` — словарный запас, `:online on|off` — включить/выключить
   сеть, `:help` — справка.

7. Проверить, что всё живо на этом устройстве:

   ```bash
   python -m rasm_cim stress --n 50 --json > stress.json
   python -m pytest tests_v17 -q        # если поставили pytest
   ```

## Проверено здесь (Linux x86_64)

* обязательных зависимостей нет: `pyproject.toml` → `dependencies = []`,
  только стандартная библиотека; `pytest`/`hypothesis` — только для тестов;
* статическая проверка сети (`python -m rasm_cim stress`): импортов сети и
  вызовов `curl`/`wget` нет нигде, кроме одного явного модуля — сетевого
  инструмента агента `rasm_cim_v17/agent/tools.py`, и он выключен по умолчанию
  (`--online`), ходит только по списку разрешённых хостов;
* замеры: холодный старт демо-базы ≈ 23 мс, запрос — p50 ≈ 0,5 мс, пик памяти
  на серию из 5 вопросов ≈ 26 КБ (CPython 3.11, десктоп);
* рост стоимости при увеличении базы с 88 до 263 утверждений: ×0,98–1,16 —
  на этих размерах стоимость вопроса от размера базы почти не зависит;
* ввод не ломает процесс: 100 «враждебных» строк (пустые, обрезанный UTF-8,
  5 тыс. символов, эмодзи, zero-width, bidi) — 0 падений;
* полный набор тестов: `tests_v16 tests_v17` — 680 passed;
  исторические `tests_v9 tests_v10` — 48 passed, 1 skipped.

## Требует устройства (не проверено — INCONCLUSIVE)

* Python 3.10+ на ARM64: платформенных ветвлений в коде нет, но прогон на
  телефоне не выполнялся;
* реальный расход RSS на Android: `tracemalloc` показывает память Python, а не
  RSS процесса; на устройстве обычно больше;
* длительная работа (часы) и поведение при нехватке памяти — не измерялись;
* `pkg install python` может дать другую версию CPython; поддерживаемая
  граница — `requires-python >= 3.10`;
* **сеть на телефоне:** в песочнице, где готовился этот документ, доступен
  только `api.github.com`, а Википедия закрыта на уровне окружения. На
  телефоне с обычным интернетом поиск по Википедии должен работать, но это
  **не проверено** — проверяйте сами:

  ```bash
  python -m rasm_cim agent "Кто такой Кулибин?" --online
  ```

  Если ответ «Не смог получить информацию: нет доступа к …» — сеть или хост
  недоступны; агент в этом случае не выдумывает ответ.

Если `stress.json` покажет падения или `p95_ms` выше сотен миллисекунд — это
находка, которую нужно записать в `PROGRESS.md`, а не «норма для телефона».
