# Termux / ARM64 — что проверено, а что нет

Целевая среда из ТЗ: Android, Termux, ARM64, ~3 ГБ RAM, без root и без GPU.
**На этой машине (Linux x86_64) проверить ARM64 невозможно**, поэтому документ
разделён на «проверено здесь» и «требует устройства».

## Проверено здесь

* нет обязательных зависимостей: v0.17 использует только стандартную библиотеку
  (`pyproject.toml` → `dependencies = []`); `pytest`/`hypothesis` нужны только
  для тестов;
* нет сетевых импортов и вызовов `curl`/`wget` — статическая проверка
  `python -m rasm_cim stress` (38 файлов, 0 нарушений);
* замеры: холодный старт демо-базы ≈ 23 мс, запрос — p50 ≈ 0,5 мс, пик памяти
  на серию из 5 вопросов ≈ 26 КБ (CPython 3.11, десктоп);
* рост стоимости при увеличении базы с 88 до 263 утверждений: ×0,98–1,16 —
  то есть на этих размерах стоимость вопроса от размера базы почти не зависит;
* ввод не ломает процесс: 100 детерминированных «враждебных» строк (пустые,
  обрезанный UTF-8, 5 тыс. символов, эмодзи, zero-width, bidi) — 0 падений.

## Требует устройства (не проверено)

* Python 3.11 на ARM64: ожидается совместимость (в коде нет платформенных
  ветвлений), но прогон на телефоне не выполнялся;
* реальный расход RSS на Android: `tracemalloc` показывает память Python, а не
  RSS процесса; на устройстве обычно больше;
* длительная работа (часы) и поведение при нехватке памяти — не измерялись;
* `pkg install python` в Termux может дать другую версию CPython; поддерживаемая
  граница — `requires-python >= 3.10`.

## Как запустить на устройстве

```bash
pkg update && pkg install python
git clone <repo> && cd Bunyod
python -m rasm_cim version
python -m rasm_cim teach "Париж находится в Франция"
python -m rasm_cim ask "Где находится Париж?"
python -m rasm_cim stress --n 50 --json > stress.json
python -m pytest tests_v17 -q          # если установлен pytest
```

Если `stress.json` покажет падения или `p95_ms` выше сотен миллисекунд — это
находка, которую нужно записать в `PROGRESS.md`, а не «норма для телефона».
