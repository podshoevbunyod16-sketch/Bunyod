## Тесты, добавленные после найденных дефектов (регрессия)

Каждый пункт — тест, который **упал** на реальном дефекте и остался в наборе:

1. `test_hypothesis_policy_is_explicit` / `test_plan_reports_skips_with_reasons` —
   гипотезы v0.12 нельзя импортировать как факты (и нельзя терять молча).
2. `test_every_mapping_target_is_a_relation_that_exists_or_is_created` —
   `может_летать`/`существует` сначала отображались в несуществующие
   `can_fly`/`exists`; теперь цель `has_property`, а смысл — в литерал.
3. `test_inverse_relations_point_at_mapped_relations` — `has_satellite.inverse`
   указывал на незарегистрированный `satellite_of`.
4. `test_single_class_artifact_has_no_margin` — зафиксировано поведение v0.15:
   у одно-классового фолбэка маржа отрицательна, порог `tau` не достигается.
5. `test_artifact_import_writes_routing_and_links_aliases` — `alias_delta`
   должен добавлять **имя** к сущности, а не требовать существующую сущность;
   при конфликте двух существующих сущностей — отказ и предупреждение.

## Что этими тестами НЕ проверено

* Python 3.14 — недоступен (в песочнице 3.11.2).
* ARM64 / Termux, реальные 3 ГБ RAM — недоступны; замеров нет.
* Реальная пользовательская база (`kb.json` v1/v2) — отсутствует в окружении.
* Импорт контекста v0.13 и журнала коррекций v0.15 — не реализован, значит и
  не тестируется.
* Качество языка (intent/entities/coreference) — нет размеченного корпуса в
  `main`; появится в Плане B на fixture-корпусе с явным указанием объёма.
