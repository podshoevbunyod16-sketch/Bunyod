# Аудит v0.2 перед v0.3 (2026-11-25)

## Известные проблемы v0.2 (из задания + код)
1. Коллизии ключей CAM: CAM2._exact dict перезаписывает при одинаковых residues+context.
2. Resonator не во всей системе: Logic2.compose и Program2.decode не вызывают Resonator2.
3. Расхождения отчёт/код: отчёт заявляет resonator в пайплайне, код — нет.
4. ProgramMemory: MAX_STEPS=3, длина 4+ невозможна; порядок как HV-последовательность хрупок.
5. Resonator vs brute: fallback скрывает отказы resonator (F4 fallback 4/20 без разбивки точности).
6. SSM: только readout-обучение, длина фиксирована (8), parity не решена.
7. Масштабируемость: тесты до N=5000, без кривых роста.
8. RNS: silent wrap за M, отрицательные не поддержаны явно, base-extension наивный.

## Метод v0.3
Сначала reproduce_bugs_v02.py (каждая ошибка — падающий/демонстрирующий тест),
затем исправления в rasm_cim_v3/ (v0.2 не трогаем), затем F-эксперименты с повторами и seed.
