# План v0.6 (полный, по исходному заданию)

**Дата:** 2026-11-25. **Статус:** реализуется как `rasm_cim_v6_v2/` (старый `rasm_cim_v6/` — урезанная попытка, сохранена для истории, НЕ удаляется).

## 1. Независимый аудит v0.5 — `docs_v6/AUDIT_v0.5.md` (уже есть, 8 ограничений). Дополнительно: reproduce скрипт для каждого пункта.

## 2. Исследование альтернативных парадигм — `docs_v6_v2/RESEARCH_paradigms.md`
CA, графы/гиперграфы, event-driven/async, SNN, dynamical/reservoir, CAM, symbolic/program synthesis, differentiable programming, Bayesian, information-theoretic, sparse/conditional, memory-centric, algorithmic, hybrids. Для каждой: принцип, задачи, ограничения, сложность, масштабирование, публикации, что прототипируется. Известное не выдаётся за своё.

## 3. Три независимых прототипа (НЕ пред-объединённые)
- **Arch-A Memory-Centric** (`memoryA.py`): ассоциативный поиск, иерархия, связи, обновление, разрешение противоречий. Отдельные тесты/метрики/отчёт.
- **Arch-B Dynamic Computational** (`dynamicB.py`): динамика/локальные взаимодействия/графы вместо последовательных токенов. CA dense/sparse, reservoir, graph propagation. Отдельные тесты/метрики/отчёт.
- **Arch-C Algorithmic** (`algorithmicC.py`): формировать/проверять/комбинировать/улучшать алгоритмы из опыта, не только выбирать из готовых. BFS-синтез + верификация + композиция + самокоррекция. Отдельные тесты/метрики/отчёт.

## 4. Тест 14 способностей (`capabilities.py` + `experiments6.py`)
Логическое рассуждение, математика, последовательности, поиск паттернов, абстракция, обобщение на новые данные, многоэтапное обучение, долговременное удержание, противоречивая информация, планирование, создание новых алгоритмов, задачи вне обучения, использование инструментов, самообнаружение/исправление ошибок. Отдельно: исполнение операции ≠ понимание новой задачи.

## 5. Память как отдельная система (`memory6.py` v2)
Иерархическая, ассоциативная, семантическая, эпизодическая, процедурная; сжатие/восстановление (RNS exact, с доказательством); дедупликация без потери уникальной информации; обновление без полного переобучения; удержание; обнаружение противоречий; контекстный поиск. Continual learning / catastrophic forgetting эксперименты. Полное удержание — только с доказательством точного восстановления.

## 6. Честное сравнение с LLM (`llm_compare.py`)
Одинаковые данные/условия, несколько повторов; точность, обобщение, качество рассуждений, память, время обучения/инференса, RAM, размер модели+данных, энергия (если измерима), масштабирование, unseen-task. Не сравнивать специализированный алгоритм на одной задаче с универсальной LLM на всех. Независимые тест-наборы с версиями, не только свои синтетические. LLM — отдельный внешний инструмент, не ядро.

## 7. Научная строгость (`hypotheses.py` + `results_v6_v2/hypothesis_registry.json`)
На гипотезу: фальсифицируемое утверждение, критерий confirm/refute, минимальный эксперимент, несколько повторов, сырые результаты сохранены, ablation, простые и сильные базлайны, публикация ограничений/негативов. Меньше ops ≠ speedup без измеренного времени; меньше кандидатов ≠ scalability без whole-system измерения; confidence=1.0 только с калибровкой/обоснованием.

## 8. Компактное вычислительное ядро (`compute_core.py`)
Без Python в рантайме (оценка C++/Rust), модульность, эффективные структуры памяти, параллель/async, ограниченная RAM, плагины, offline. Не переписывать весь проект до доказательства преимущества нового ядра.

## 9. Масштабирование по устройствам (`profiles.py` v2)
Mobile (Android/Termux, ограниченная RAM, CPU-first), Desktop (multithread, больше RAM, опционально GPU), Server (большая память, distributed, multi-node). Реальные измерения памяти/скорости/хранилища на режим. Не объявлять phone-ready по одному тесту Android.

## 10. Структура проекта v0.6 (с сохранением совместимости v0.5)
```
rasm_cim_v6_v2/
  architectures/  (A/B/C)
  memory/         (память как система)
  learning/       (continual, BPTT selective SSM)
  reasoning/      (динамика, графы, CA)
  synthesis/      (программный синтез)
  compute/        (компактное ядро)
  benchmarks/     (LLM-сравнение, базлайны)
  experiments/    (14 способностей, ablation, calibration)
  mobile/ desktop/ (профили устройств)
  reports/        (отчёты)
  tests/          (автотесты)
```
Каждый модуль — с рабочей реализацией и тестами. Никаких фиктивных модулей.
