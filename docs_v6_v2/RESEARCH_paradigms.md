# Исследование альтернативных парадигм (§2)

**Дата:** 2026-11-25. Известное не выдаётся за своё; ссылки на публикации/реализации.

| Парадигма | Принцип | Задачи | Ограничения | Сложность | Масштабирование | Публикации/реализации | Прототип в v0.6 |
|---|---|---|---|---|---|---|---|
| CA / локальные правила | Локальные обновления клеток, параллелизм | Parity, паттерны, генерация | Трудно обучать; 2D дорого | O(N) шаг, O(N·T) | Линейно по клеткам | Wolfram; Rule 110 Тьюринг-полон | Arch-B CA dense/sparse ✓ |
| Графы/гиперграфы | Рёбра = отношения, обход = рассуждение | Логика, KG, планирование | Нет градиентов; ручные правила | O(V+E) обход | До млн рёбер (SPARQL) | RDF/SPARQL; Neo4j | Arch-A semantic, Arch-B propagate ✓ |
| Event-driven/async | Вычисления только при событии | Sparse данные, датчики | Сложная синхронизация | O(активных) | Отлично на sparse | CIM-SSM Nat Commun 2026 | Sparse CA ✓ (частично) |
| SNN/нейроморфные | Спайки, STDP, энергия ∝ событиям | SHD, DVS, low-power | Точность ниже ANN; обучение трудно | O(событий) | Отлично на железе | Loihi, TrueNorth | НЕ реализовано (ограничение) |
| Dynamical/reservoir | Фиксированная динамика + обучаемый readout | Последовательности, хаос | Забывает ранние входы (firstbit 0.56) | O(N²) матрица | Средне | Echo State Networks (Jaeger) | Arch-B reservoir ✓ |
| Associative/CAM | Параллельный поиск по содержимому | Точный/нечёткий поиск | Плотность/энергия в железе | O(1) аппаратно | До млн записей | CAMformer 2025; TCAM | Arch-A L1/L2/L3 ✓ |
| Symbolic/program synthesis | Поиск программ по примерам | Алгоритмы, правила | Экспонента по глубине | O(b^d) | Плохо по глубине | FlashFill; SyGuS | Arch-C BFS ✓ |
| Differentiable programming | Градиенты через программы | Структурированные задачи | Сложно дифференцировать ветвления | O(программа) | Средне | DeepCoder | НЕ реализовано |
| Bayesian/probabilistic | Вероятностные модели, неопределённость | Малые данные, калибровка | Вычислительно дорого | Зависит от вывода | Средне | PyMC, Stan | Калибровка tau (частично) |
| Information-theoretic | Сжатие, MDL, энтропия | Компрессия, отбор признаков | Не интеллект сам по себе | O(N log N) | Хорошо | Huffman, LZ | RNS exact (не сжатие) |
| Sparse/conditional | Активация части сети | Большие модели, MoE | Маршрутизация сложна | O(k) из N | Хорошо | MoE (Switch Transformer) | Sparse CA ✓ |
| Memory-centric/in-memory | Вычисление в памяти, без перемещения данных | Поиск, SSM, HDC | Технология (мемристоры) | O(1)–O(N) | Зависит от железа | Nat Commun 2026 HDC-CIM | Симуляция (не железо) |
| Algorithmic (без NN) | Формировать/проверять/комбинировать алгоритмы | Точные задачи | Нет обобщения из данных | O(b^d) поиск | Плохо по глубине | BFS/DP/A* | Arch-C ✓ |
| Hybrids | Комбинация принципов | Разные | Сложность интеграции | Сумма | Зависит | Neurosymbolic (Clingo+LLM) | NEXTGEN v0.5 (не пред-объединён в v0.6) |

**Вывод:** ни одна парадигма не универсальна. v0.6 прототипирует CA, графы, reservoir, CAM, синтез, sparse, memory-centric. SNN, differentiable programming, Bayesian — не реализованы (честно).
